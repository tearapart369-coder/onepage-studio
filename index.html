The One Page

If a step is not here, it is not part of the system.

  1. Pick 1 distinct idea
  2. Write a 60–90 second script
  3. Prepare 8–15 slides (one idea, one proportion, one light, one focal curve)
  4. Record or generate narration
  5. Add music + captions
  6. Run the QC checklist
  7. Publish + launch for 48 hours
  8. Review analytics and save what worked

Visual Standard (incorporated)

Every slide carries one clear idea. The image or figure on that slide carries one proportion, one light direction, and one focal curve. Structure stays clean; surface stays intentional.

Content Type Note

Story / emotional: proof is a lived moment. Educational: proof is a number, before/after, or clear example. Same skeleton, different weight on proof and ending.

Idea Filter

Answer these before any production. Distinct does not mean weird — it means specific angle + clear promise.

Distinctness test: “Could 100 other channels make this exact video today?” If yes, change the angle.
